# Quiz Platform 

A web-based Quiz Management and Online Assessment Platform that allows administrators to create and manage quizzes, categories, and questions, while students can attempt quizzes, view results, review answers, and check their performance.

---

##  Project Overview

The Quiz Platform is designed to provide an online environment for conducting and managing quizzes.

The system has two main types of users:

- Admin
- Student

Admins can manage users, categories, quizzes, and questions. Students can view available quizzes, attempt quizzes, view results, review answers, and check their attempt history and leaderboard position.
